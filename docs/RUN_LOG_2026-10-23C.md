## The new voice path, driven over HTTP on the clean clone

Two calls, exactly what the demo page does:

```bash
curl -s -H 'content-type: application/json' \
  -d '{"utterance":"set up a movie night for everyone","session":"runlogC","hour":23}' \
  http://localhost:8787/api/agent

curl -s -H 'content-type: application/json' \
  -d '{"utterance":"why did that change?","session":"runlogC"}' \
  http://localhost:8787/api/agent
```

The second call, from the actual response:

```json
{
  "secondIntent": "explain",
  "secondTrace": ["household_profile", "describe_last_decision"],
  "spoken": "Last time I ran Family movie night at 05:12. I ran 9 steps: 4 added as the plan changed, 0 skipped. The one that mattered - media_search: Past the 22:00 screen-time curfew - offering audio instead of video",
  "decisionToolsInOrder": ["household_profile","weather_now","media_search","pantry_status","media_search","learn_fact","media_search","media_search","place_order"],
  "added": ["media_search","learn_fact","media_search","media_search"]
}
```

Two things this proves that the earlier logs did not:

- `explain` is a real intent in `src/agent.js`, and it **plans a tool call** — `describe_last_decision`
  appears in the routine's own trace, so the explanation goes through the same MCP surface as everything else.
- The reason text in the spoken answer ("Past the 22:00 screen-time curfew - offering audio instead of
  video") is byte-identical to the `why` the planner wrote mid-run. It is read back from the persisted
  trace, not re-derived for the answer.

`ui://aura/decision` was previously served over MCP but never displayed. On the demo page it is now a third
sandboxed frame, and driving **this clean clone** in a browser (clock 23:05 → *set up a movie night for
everyone* → *why did that change?*) filled it with:

The frame grew from its 160 px placeholder to 1042 px on the `ui/size-changed` handshake, and its contents
are the persisted trace — the same nine tools in order and the same four `why` strings the HTTP response
returned above. Before any routine runs, the same frame honestly says *"Nothing to explain yet — run a
routine, then ask 'why did that change?'"* rather than showing a fabricated trace.
