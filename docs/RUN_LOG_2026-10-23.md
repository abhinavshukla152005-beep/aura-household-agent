## The MCP surface, measured rather than described

A throwaway script connected a real `Client` + `StreamableHTTPClientTransport` to `/mcp`, listed tools, and
called the new tool:

```js
const { tools } = await client.listTools();                       // 14 advertised tools
const r = await client.callTool({ name: 'describe_last_decision', arguments: {} });
```

Returned (abbreviated, from the actual response):

```json
{
  "found": true,
  "traceAvailable": true,
  "routineName": "Good morning briefing",
  "committedAt": "2026-10-23T00:04:08.578Z",
  "spend": 0,
  "toolsInOrder": ["household_profile","weather_now","news_briefing","news_briefing","pantry_status","learn_fact"],
  "addedByAgent": [{ "tool": "learn_fact", "why": "Low-stimulation replacement" }],
  "skippedSteps": [{ "tool": "news_briefing", "reason": "..." }]
}
```

with `_meta.ui.resourceUri = "ui://aura/decision"` and the same payload as spoken `content[]`.

`addedByAgent[0].why` is the planner's own reason string ("Low-stimulation replacement" is what
`src/agent.js` writes for the quiet-hours substitution), not a paraphrase — which is the point of the tool:
the re-plan and the skip are reported from the trace that was persisted when the routine committed.
